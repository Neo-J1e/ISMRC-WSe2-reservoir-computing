# Supplementary Note 6 — Repeatability, stability, parameter variation

Regenerates the numbers quoted in **Supplementary Note 6** and the panels of
**Supplementary Figures 10–14**, and verifies the raw acquisition data they
derive from.

## Run

```bash
python analyze_note6.py                 # analysis, figures and self-check
python analyze_note6.py --no-figures    # tables only (much faster)
python analyze_note6.py --no-check      # skip the comparison with the SI

python check_raw_provenance.py          # raw files -> derived data (writes nothing)
```

No absolute path is hard-coded. The permutation test is seeded
(`numpy.random.default_rng(20260921)`) and the seed is consumed device by
device in the order Device 1 … Device 5, so the reported p-values are exactly
reproducible.

### How the endpoint voltages are obtained

```python
endpoint[device, cycle, mask] = trace[f"{device}_{cycle}_{mask}"][applied_off_index]
```

`trace` is column 2 of the corresponding raw CSV; `applied_off_index` is the
visually reviewed response-knee index from the alignment sheets. This is the
same rule that produced the manuscript values.

## Method

* **Five-device repeatability.** For each device the endpoint voltages form a
  5 × 16 matrix (cycles × masks). The cycle-to-cycle sample standard deviation
  (ddof = 1) is computed per mask; the mask effect is tested by a Friedman
  statistic evaluated against 99 999 within-cycle label permutations, with a
  Holm correction across the five devices. Device-to-device similarity is the
  Pearson correlation between the two 16-element mean response profiles.
  Mask identification uses a leave-one-cycle-out nearest-centroid classifier.
* **Stability.** Each 8000-point record is split into eight chronological blocks
  of 1000 points; the block-mean shift is measured against block 1.
* **Parameter variation.** Each light-on transient is fitted with a
  single-exponential approach over 0.30–6.18 s after the response onset.
* **Perturbation sensitivity.** Independent zero-mean Gaussian perturbations are
  applied to the fitted response target `A` and the response time constant `τ`
  at every mask interval — *not* to the optical input. The scanned standard
  deviations are absolute, in volts and seconds respectively. Every level uses
  20 independent realisations; the error bars are two-sided 95 % Student-t
  confidence intervals of the mean. The readout is fitted and scored on the same
  2000 samples, i.e. these are in-sample results.
