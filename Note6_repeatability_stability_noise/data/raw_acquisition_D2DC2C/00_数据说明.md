# D2DC2C 原始采集数据说明

打包日期：2026-10-10（2026-10-10 精简：移除了每次采集的 Runlog 与批次自查记录）

本目录是采集时的原始目录结构，文件名与采集软件写出的一致。

## 1. 内容

| 目录 | 内容 | CSV 数 |
|---|---|---|
| `01_恒定mask_50条_Note6标定用/` | 参数变化标定实际使用的 50 条：五器件 × {0000, 1111} × 5 cycle。文件名格式 `DeviceN_内部编号_c轮次_mask.csv` | 50 |
| `02_五器件_全部16种mask_400条/` | 同一五器件的完整原始记录：16 种 mask × 5 cycle，保持采集当时的目录结构 | 400 |
| `清单_SHA256.csv` | 全部数据文件的相对路径、字节数、SHA-256，并标注 device_label / device_folder / cycle / mask（清单自身不收录，避免自引用哈希） | — |

合计 450 个记录 CSV，加上 `清单_SHA256.csv` 与本说明，共 452 个文件、约 18.0 MB；清单收录其中 451 个文件的校验值（不含清单自身）。

> 采集软件随每条记录生成的 `*-Runlog.txt`（400 个）与每个 run 的 `batch_health.txt`（25 个）共约 0.8 MB 未收入本包；逐条质量指标见 `…\data\parameter_variation\protocol_trace_qc.csv`。采集参数的权威来源为正文 Methods 与 Supplementary Information。

## 3. 文件格式

- 每个 CSV：1210 行 × 4 列，制表符分隔，无表头；第 1、3 列为固定代码（201、301），**第 2 列为响应电压（V）**。
- 采集时的实验参数——采样设置、栅压与极性编制、光功率、光照时序等——**一律以正文 Methods、Supplementary Information 及 Response to Referees' Comments 中的表述为准**。本说明不重复这些参数，以免与正式稿件产生不一致。
- 每个器件的 5 个 cycle 为顺序重复，不是随机化的独立重复；重复性统计据此解释。

## 5. 完整性校验

`清单_SHA256.csv` 中每行的 `sha256` 为该文件的 SHA-256（小写十六进制）。逐文件校验（PowerShell）：

```powershell
$bad = Import-Csv .\清单_SHA256.csv |
    ForEach-Object {
        $h = (Get-FileHash -LiteralPath (Join-Path $PWD $_.relative_path) -Algorithm SHA256).Hash.ToLower()
        if ($h -ne $_.sha256) { $_.relative_path }
    }
if ($bad) { "不一致: $bad" } else { "全部一致" }
```

同目录（`check_raw_provenance.py`）另提供 Python 版校验，并额外核对派生矩阵与原始 CSV 第 2 列是否逐点一致。

## 6. 英文表述（可直接用于 Data Availability）

> The raw acquisition files underlying the repeated-measurement analysis are provided as tab-delimited 1210 × 4 matrices; column 2 is the measured response voltage in volts. A manifest listing the relative path, byte size and SHA-256 of every file is included, together with the device, cycle and mask labels for each record. Acquisition parameters are stated in the Methods, the Supporting Information and the response to referees.
